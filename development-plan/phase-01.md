# فاز ۰۱: زیرساخت پایه، پوسته PWA و سیستم دیزاین اتمیک
## Phase 01: Foundation, PWA Shell & Atomic Design System

---

## ۱. هدف فاز (Objective)
استقرار پروژه پایه‌ای Next.js (App Router) با تایپ‌اسکریپت و تیلویند، پیکربندی الزامات بنیادین PWA (مانیفست، متاتگ‌ها و سرویس‌ورکر)، استقرار ۱۰۰٪ محلی قلم وزیرمتن (بدون وابستگی ریموت)، پیاده‌سازی توکن‌های پالت اولترامارین-سیترون با پشتیبانی از حالت شب، راه‌اندازی کامپوننت‌های پایه دیزاین سیستم اتمیک، چیدمان واکنش‌گرای پوسته برنامه (سه‌ستونه دسکتاپ و ۴ گزینه‌ای موبایل)، و اجرای مایگریشن کامل اسکیما پایگاه‌داده MySQL / MariaDB (موتور InnoDB و انکودینگ utf8mb4_unicode_ci) همراه با کلاینت‌های ردیس و پوشه ذخیره‌سازی محلی uploads (و آمادگی S3/MinIO).

---

## ۲. چک‌لیست وظایف اجرایی (Task Checklist)

### الف) ساختار پروژه و محیط اجرایی
- [ ] راه‌اندازی پروژه Next.js بر پایه App Router با زبان TypeScript و ابزار Tailwind CSS.
- [ ] تنظیمات جهت‌گیری راست‌به‌چپ (`dir="rtl"` و `lang="fa"`) در `layout.tsx` و فعال‌سازی کلاس‌های فاصله‌گذاری منطقی Tailwind (`ms-`, `me-`, `ps-`, `pe-`).
- [ ] میزبانی محلی فونت وزیرمتن (Vazirmatn) با فرمت‌های بهینه `woff2` در مسیر `/public/fonts/vazirmatn/` با استفاده از `next/font/local` و حذف کامل هرگونه ارجاع به Google Fonts CDN.

### ب) پیکربندی و الزامات PWA (Progressive Web App)
- [ ] ایجاد فایل `manifest.json` در مسیر `/public/` شامل نام، نام کوتاه («توییت‌تحلیل»)، آیکون‌های استاندارد (192x192 و 512x512 ماسک‌پذیر)، `theme_color: "#3949D8"`، `background_color: "#F7F7FB"` و `display: "standalone"`.
- [ ] افزودن متاتگ‌های لازم در سربرگ HTML برای قابلیت نصب‌پذیری در iOS و اندروید.
- [ ] راه‌اندازی ساختار رجیستری اولیه Service Worker در سمت کلاینت.

### ج) توکن‌های رنگی، حالت شب و سیستم طراحی اتمیک
- [ ] تعریف متغیرهای سراسری CSS در `globals.css` و ادغام در `tailwind.config.ts`:
  - اولترامارین (`#3949D8`)، هاور (`#2C37B3`)
  - سیترون اسیدی (`#E5F05B`)
  - پس‌زمینه پرسلین (`#F7F7FB`)، سطح کارت سفید (`#FFFFFF`)، حاشیه (`#E4E5F0`)
  - متون تیره (`#242747`) و ثانویه (`#656985`)
  - پالت کامل حالت شب (`dark:`): پس‌زمینه `#0D1021`، سطح `#151933`، حاشیه `#262E56`
  - ارقام تراز مالی `tabular-nums`
- [ ] پیاده‌سازی کامپوننت‌های اتمیک پایه (`/src/components/ui/`):
  - `Button`: دارای حالت‌های primary، secondary، ghost، citron-highlight و وضعیت‌های هاور، فوکوس و غیرفعال.
  - `Input` / `Textarea`: ورودی‌های فارسی با بوردر ظریف و حلقه فوکوس اولترامارین.
  - `Avatar`: نمایش مدور تصویر کاربر با حالت Fallback حروف اختصاری.
  - `CashtagBadge`: کپسول استایل‌دهی‌شده با رنگ لاوندر برای `$نماد`.
  - `HashtagBadge`: پیوند آبی برای هشتگ‌های عمومی `#موضوع`.
  - `VerificationBadge`: نشان‌های آبی تحلیل‌گر (`#303EB9` روی `#E5E7FF`) و نشان سازمانی تیره روی سیترون (`#242747` روی `#E5F05B`).
  - `FinancialNumber`: رندر ارقام با `tabular-nums` و تفکیک رنگ مثبت (`#168253`) و منفی (`#C63849`).
  - `Modal`: پنجره گفت‌وگوی شناور با لایه پس‌زمینه محو و انیمیشن مقیاس ملایم.
  - `SkeletonLoader`: پالس نوری آرام برای کارت‌ها و سطوح پیش از لود اطلاعات.

### د) قالب‌های چیدمان کلان واکنش‌گرا (Layout Templates)
- [ ] `DesktopThreeColumnLayout`: سه‌ستونه دسکتاپ (منوی راست ۲۸۰px، فید میانی ۶۴۰–۶۸۰px، سایدبار چپ ۳۴۰px).
- [ ] `MobileAppLayout`: نوار پایین ۴ گزینه‌ای راست‌به‌چپ: **خانه | کاوش | پروفایل | تنظیمات** به همراه هدر بالا (لوگو، سرچ، اعلان‌ها) و دکمه شناور ارسال (+).

### هـ) پایگاه‌داده و زیرساخت داده‌ها
- [ ] راه‌اندازی اتصال به پایگاه داده MySQL 8.0+ / MariaDB 10.5+ با انکودینگ `utf8mb4` و تطبیق `utf8mb4_unicode_ci`.
- [ ] پیاده‌سازی اسکریپت مایگریشن کامل بر مبنای سند `02-data-model-and-database-schema.md`:
  - جداول: `users`, `stocks`, `posts`, `post_attachments`, `post_stocks`, `post_hashtags`, `follows`, `stock_follows`, `likes`, `bookmarks`, `verification_requests`, `reports`, `notifications`, `system_configs`, `ai_summaries`, `security_logs`, `otp_codes`, `sessions`, `user_settings`, `audit_logs`, `user_blocks`, `user_mutes`, `ai_morning_briefs`.
  - ایندکس‌های کلیدی: `ft_content` (ایندکس FULLTEXT فارسی)، ایندکس‌های نمادها، جستجوی نام کامل شرکت، فیدها و روابط.
- [ ] پیکربندی کلاینت اتصال به MySQL (درایور mysql2 pool یا ORM).
- [ ] پیکربندی کلاینت اتصال به Redis (ioredis) با پشتیبانی از تست سلامت (Ping) یا کش In-Memory در محیط محلی.
- [ ] پیکربندی مسیر ذخیره‌سازی محلی فایل‌ها (`public/uploads`) و آمادگی آداپتور S3/MinIO.

## ۴. خروجی مورد انتظار (Expected Outcome)
1. برنامه بدون خطا در پورت توسعه بیلد و اجرا شود (`npm run build` و `npm run dev` با موفقیت).
2. باز کردن برنامه در مرورگر، پوسته PWA با فونت محلی وزیرمتن، استایل RTL، پالت اولترامارین-سیترون و سوئیچ حالت روز و شب را بدون هیچ درخواست خارجی نمایش دهد.
3. دیتابیس MySQL تمام جداول، ایندکس‌ها، انوم‌ها و روابط را با موفقیت دریافت و آماده ذخیره‌سازی کرده باشد.
4. اتصالات دیتابیس، کش و مسیر آپلود فعال باشند.
