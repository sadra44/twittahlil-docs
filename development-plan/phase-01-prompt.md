# پرامپت اجرایی فاز ۰۱: زیرساخت پایه، پوسته PWA و سیستم دیزاین اتمیک
## Execution Prompt for AI Coding Agent — Phase 01

---

### دستورالعمل برای عامل برنامه‌نویسی هوش مصنوعی (AI Coding Agent):

شما در حال اجرای **فاز ۰۱ از پروژه ساخت Progressive Web Application (PWA) شبکه اجتماعی بازار سرمایه ایران (توییت‌تحلیل / Twittahlil)** هستید.

وظیفه شما پیاده‌سازی کامل الزامات این فاز، آزمایش صحت عملکرد آن، و ثبت مستندات تحویل برای فاز بعدی است.

---

### ۱. فایل‌های مرجع که پیش از آغاز کار باید مطالعه کنید:
1. سند مشخصات فاز فعلی: `/development-plan/phase-01.md`
2. نقشه راه کلان پروژه: `/development-plan/development-roadmap.md`
3. تصمیمات معماری کلیدی: `/bourse-social-docs/00-architecture-and-index/architecture-decision-log.md` (به‌ویژه ADR-010، ADR-011 و ADR-019)
4. سیستم دیزاین و پالت اولترامارین-سیترون: `/bourse-social-docs/02-ux-and-design-system/02-design-system-and-persian-tokens.md`
5. اسکیما کامل MySQL / MariaDB و ایندکس‌ها: `/bourse-social-docs/04-technical-architecture/02-data-model-and-database-schema.md`
6. قراردادهای کدنویسی و درخت پوشه‌ها: `/bourse-social-docs/05-delivery-roadmap-and-testing/03-ai-coding-agent-prompts-and-conventions.md`

---

### ۲. دامنه وظایف اجرایی در فاز ۰۱:
1. **پیکربندی پایه Next.js (App Router):** با TypeScript و Tailwind CSS در قالب راست‌به‌چپ (`dir="rtl"`, `lang="fa"`).
2. **الزامات PWA:** فایل `manifest.json` استاندارد با نام «توییت‌تحلیل»، تم رنگی `#3949D8`، آیکون‌های متناسب و ثبات کلاینت Service Worker.
3. **سیاست انحصار مطلق به دارایی‌های محلی (Local-First):** فونت وزیرمتن (Vazirmatn) را از فایل‌های محلی `.woff2` بارگذاری کنید. هرگز از Google Fonts CDN یا لینک‌های خارجی استفاده نکنید.
4. **سیستم دیزاین اتمیک (پالت اولترامارین-سیترون):**
   * پیاده‌سازی رنگ‌های روز و شب در `globals.css` و `tailwind.config.ts`.
   * ساخت کامپوننت‌های پایه در `/src/components/ui/` (`Button`, `Input`, `Avatar`, `Modal`, `SkeletonLoader`, `CashtagBadge`, `VerificationBadge`, `FinancialNumber`).
5. **پوسته‌های چیدمان (Layouts):**
   * پوسته سه‌ستونه دسکتاپ (منو راست ۲۸۰px، فید وسط ۶۴۰-۶۸۰px، سایدبار چپ ۳۴۰px).
   * پوسته موبایل با نوار پایین ۴ گزینه‌ای راست‌به‌چپ (خانه، کاوش، پروفایل، تنظیمات) و هدر فشرده بالا.
6. **پایگاه داده و کلاینت‌ها:**
   * اجرای اسکریپت مایگریشن کامل MySQL / MariaDB بر اساس DDL سند `02-data-model-and-database-schema.md` شامل تمامی جداول، انوم‌ها، کلیدهای خارجی و ایندکس FULLTEXT فارسی.
   * راه‌اندازی کلاینت اتصال به MySQL، ردیس و مسیر آپلود فایل‌ها با قابلیت تست اتصال.

---

### ۳. استانداردهای فنی و کیفیت کد:
* از کدهای تمیز، تایپ‌های صریح TypeScript و ماژولار بودن بدون وابستگی تخریب‌کننده استفاده کنید.
* در جزئیات فنی که در مستندات مشخص نشده‌اند، بهترین تصمیم منطقی مهندسی را اتخاذ کنید و آن را مستند سازید.
* اجرای بیلد موفقیت‌آمیز پروژه (`npm run build`) الزامی است.
